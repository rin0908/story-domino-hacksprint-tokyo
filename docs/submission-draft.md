## Project Name

物語のドミノ / Story Domino

## 作品説明

物語の設定をひとつ変えると、関係する場面を探索し、修正案を比較して採用・取り消しできる日本語Webアプリです。

デモは『消えたデモ ― 発表まであと2分』。全員が「誰かが作っている」と思っていたハッカソンチームの喜劇を、「実はデモは完成していた」という前提へ変更します。場面1・2を維持しながら、場面3・4・5の続きを見直します。

スポンサーに関係する架空のハッカソン喜劇であり、実在企業の障害や発言を描いたものではありません。
